* XXXX-COLR.otf = intended for web browsers
* XXXX-SVG.otf = intended for apps like Adobe Photoshop
* XXXX-sbix.ttf = intended for Apple-related apps
* XXXX-CBDT.ttf = intended for Google-related apps

If one version doesn't work, try the other. If NONE of these work, let me know! Email me nick15@pokemonaaah.net
