# 版本记录

字体版本遵循 SemVer。**Major** 表示删除 ligature、改变既有文本映射或移除字形；**Minor** 表示新增符号或兼容别名；**Patch** 为视觉修正。

## Sigilora Magic 1.0.0

_首个版本。_

- 全量字体 `Sigilora Magic`，包含默认、阴影、扁平三种样式（通过 `ss01` / `ss02` 切换）。
- Lite 字体 `Sigilora Magic Lite`，仅默认样式。
- 114 个符号，覆盖法术力、混血、非瑞、其他、特殊与忠诚计数器。
- COLRv0。
