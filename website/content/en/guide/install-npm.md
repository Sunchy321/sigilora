# npm package

All game fonts ship in a single npm package: `@sigilora/fonts`.

```bash
npm install @sigilora/fonts
```

The package provides per-game CSS and WOFF2 entries. Import only the game entry you need; the browser only requests the WOFF2 you actually reference.

See [Installation](/docs/guide/install) for CSS usage.
