# Changelog

Sigilora ships one font per game, each with an independent version. Version history is tracked per game:

- [Magic: The Gathering](/docs/guide/changelog-magic) — `Sigilora Magic`
- [Lorcana](/docs/guide/changelog-lorcana) — `Sigilora Lorcana`
- [Riftbound](/docs/guide/changelog-riftbound) — `Sigilora Riftbound`
- [Pokémon TCG](/docs/guide/changelog-pokemon) — `Sigilora Pokemon`

Font versions follow SemVer: a **Major** bump removes ligatures, changes existing text mappings, or removes glyphs; a **Minor** bump adds symbols or compatible aliases; a **Patch** is a visual fix.
