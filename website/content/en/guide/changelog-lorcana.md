# Lorcana

Version history and compatibility notes for the **Sigilora Lorcana** font.

Sigilora Lorcana ships as the `Sigilora Lorcana` family (default style) and the lite `Sigilora Lorcana Lite` family. The current release covers 7 symbols — strength, willpower, lore, move-cost, ink, inkwell, and exert — using COLRv0.

Font versions follow SemVer: a **Major** bump removes ligatures, changes existing text mappings, or removes glyphs; a **Minor** bump adds symbols or compatible aliases; a **Patch** is a visual fix.

## Sigilora Lorcana 1.0.0

- Add the Lorcana symbol set: `{S}` strength, `{W}` willpower, `{L}` lore, `{M}` move-cost, `{I}` ink, `{C}` inkwell, `{E}` exert.
