# Desktop

Desktop fonts are published as TTF files with each GitHub Release.

1. Download the release archive `Sigilora-Fonts-<version>.zip`.
2. Extract it and install the `.ttf` files (double-click on macOS or Windows).
3. Select the font in your application — for example **Sigilora Magic** or **Sigilora Lorcana**.

For the COLRv1 families — full Pokémon TCG and Riftbound, and Riftbound Lite — the archive also contains a `… V0` TTF: the same font encoded in COLRv0. Install the regular family for normal use; install the `… V0` family only when the app renders text in a context without COLRv1, such as an embedded WebKit webview. Pokémon TCG Lite is already a COLRv0 font, so it has no `V0` variant.

See [Installation](/docs/guide/install) for web usage.
