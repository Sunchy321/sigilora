# Desktop

Desktop fonts are published as TTF files with each GitHub Release.

1. Download the release archive `Sigilora-Fonts-<version>.zip`.
2. Extract it and install the `.ttf` files (double-click on macOS or Windows).
3. Select the font in your application — for example **Sigilora Magic** or **Sigilora Lorcana**.

See [Installation](/docs/guide/install) for web usage.
